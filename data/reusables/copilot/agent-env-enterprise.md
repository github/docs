Agent sessions on {% data variables.product.github %} can run in a cloud sandbox or on {% data variables.product.prodname_actions %}. Compute costs from both environments draw on the same monthly allowance.

* A cloud sandbox is a faster, lightweight environment that allows users to resume sessions in {% data variables.product.github %}'s chat interface or in other clients.
* {% data variables.product.prodname_actions %} gives you more control over the environment, such as secrets and variables, setup steps to install dependencies, and access to self-hosted runners or private networking.
