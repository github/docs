Bring your own key (BYOK) allows you to use {% data variables.product.prodname_copilot_short %} with compatible models that you or your organization configure.

There are two ways to configure access to additional models:

* Users can configure additional models for themselves in a supported {% data variables.product.prodname_copilot_short %} client.
* Enterprise owners, and organization owners with the necessary permissions, can make additional models available to eligible users in their enterprise or organization through {% data variables.product.github %}'s {% data variables.product.prodname_copilot_short %} API.

Your ability to access additional locally hosted or cloud-hosted models depends on the surface in which you're using {% data variables.product.prodname_copilot_short %} and the configuration method used to add models. For example, user-configured BYOK in {% data variables.copilot.copilot_cli_short %} can connect to a compatible cloud-hosted service or a model server running on your computer or network.
