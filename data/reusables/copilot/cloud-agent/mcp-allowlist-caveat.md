`allowedMcpServers` and `deniedMcpServers` apply to MCP servers defined in user settings and repository settings, but **don't** apply to MCP servers defined in repository custom agent profiles. However, you can prevent use of MCP servers configured in custom agent profiles by ensuring that any required domains to start them are not allowed by the organization or repository-level custom firewall. See [AUTOTITLE](/copilot/how-tos/agents/copilot-coding-agent/customizing-or-disabling-the-firewall-for-copilot-coding-agent).
