The repository containing the configuration file can be public, internal, or private. To use a file from an internal or private repository other than the one being analyzed with default setup, you must set up a _Git Source_ private registry configuration. We recommend setting the registry URL to the full URL of the repository containing the configuration file, rather than the organization URL, so that the credentials are only used for requests to that repository. See [AUTOTITLE](/code-security/how-tos/secure-at-scale/configure-organization-security/manage-usage-and-access/giving-org-access-private-registries).
