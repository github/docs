# Bản dịch Tiếng Việt — GitHub Docs (vi-vn)

Thư mục này chứa bản dịch tiếng Việt của tài liệu GitHub Docs.

## Cấu trúc

```
translations/vi-vn/
├── content/     ← Bản dịch Markdown của content/ (EN)
└── data/        ← Bản dịch data/ variables và reusables
```

## Trạng thái dịch

- **Ngôn ngữ:** Tiếng Việt (Vietnamese)
- **Mã ngôn ngữ:** `vi`
- **Locale:** `vi-vn`
- **Endpoint:** `https://docs.github.com/vi`
- **Người khởi xướng:** [@Dennis-nham](https://github.com/Dennis-nham) · NLP Labs Vietnam
- **Tổ chức:** [@nlp-labs-vietnam](https://github.com/nlp-labs-vietnam)

## Cách đóng góp

1. Xem danh sách bài chưa dịch tại [GitHub Discussions](https://github.com/github/docs/discussions)
2. Nhận bài dịch: comment vào discussion tương ứng
3. Dịch file `.md` trong `content/` — giữ nguyên frontmatter, code block, và Liquid tags
4. Gửi PR vào repo dịch riêng (khi GitHub tạo private translation repo cho `vi-vn`)
